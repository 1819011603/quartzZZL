# 工单排查记录

这里保存飞书转发的线上问题和工单结论，与 `需求/` 分开。按业务模块建一个中文子目录，同一模块的所有案例按日期倒序写入同一份 `README.md`。

## 使用规则

- 收到“查工单、查问题、帮我看看线上反馈”时，先用 `gaotu-ticket-triage` 搜索本目录。
- 优先搜索原始报错、字段名、接口名、userId、班级号、traceId 等高区分度信息。
- 历史命中只是线索；关键对象、现象和证据链一致才能复用结论。
- 只有用户明确要求“记录、沉淀、补充或更新工单”时才写入。
- 新案例使用 [`_template.md`](_template.md)。模块已存在就在原 README 顶部新增日期小节，不为单个工单新建文件。
- 本目录只保存案例事实、证据和决策。SQL、日志语法、接口重放、回溯步骤等通用方法放在对应项目 skill；工单只保留指针。
