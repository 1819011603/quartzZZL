# 工单排查记录

跟 `需求/` 同级，但存的不是需求开发过程，是**用户在飞书里转发的线上问题/工单**排查出来的结论。
按业务模块建子目录（纯中文模块名，如 `企微侧边栏/`），同一模块的多个工单**都写进同一份
`README.md`**，按时间倒序追加成 `## YYYY-MM-DD <一句话问题>` 小节，不为单个工单再拆子目录/子文件。

## 怎么用

- 用户贴一段飞书转发消息、说"帮我看看这个问题/工单"→ **先在这个目录下搜关键词**，
  命中说明之前排查过，直接给结论 + 链接，不用重新查日志代码。
- 排查完一个新工单：模块目录已存在 → 追加一个新小节；不存在 → 建目录，按
  [`_template.md`](_template.md) 起草第一个小节。
- 结论里但凡涉及"以后怎么排查这类问题"的**可复用方法**（怎么查日志、怎么用 acl 桥重放、
  哪个 traceId 格式），**不要**照抄进这里——那是对应项目仓库里的 project skill 该收的东西
  （比如 crm-service 的 `wk-student-info-replay`）。这里只存指针，不存方法本身，否则跟 skill 分叉。
