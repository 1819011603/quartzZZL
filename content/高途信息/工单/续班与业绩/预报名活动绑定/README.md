# 预报名活动绑定

续班计划的预报名节点到底绑定了哪个预报名活动、活动被删后代课/花名册为何仍能看到：绑定权威表、与活动主表的交叉核验、删除不级联的根因。

## 症状路由

| 症状（用户会怎么说） | 去哪 |
|---|---|
| 续班计划绑的是哪个预报名活动 / 按计划号查不到绑定 | [`续班计划绑定的哪个预报名活动.md`](排查/续班计划绑定的哪个预报名活动.md) |
| 预报名活动删了，但计划下的班/代课还能看到预报名活动 | [`续班计划绑定的哪个预报名活动.md`](排查/续班计划绑定的哪个预报名活动.md) |
