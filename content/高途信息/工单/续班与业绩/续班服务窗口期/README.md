# 续班服务窗口期

辅导班花名册「续班服务」页显示的续班期/非续班期（= 班级是否在续班计划窗口内）的核验与恢复方法。

> 与判单配置的「保护期 / 可续讲次」（performance-attribution）不是一回事：后者管业绩归属窗口，这里的「续班期」只由**续班计划**窗口决定。

## 症状路由

| 症状（用户会怎么说） | 去哪 |

| 某班级在续班服务里显示「非续班期」（本该在续班期） | [`续班服务显示非续班期.md`](排查/续班服务显示非续班期.md) |
