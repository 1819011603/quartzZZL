# 续班看板 · 看板与指标如何查询

> **只解决**：想搞清楚某个续班/预报名大盘指标（如「预报名状态延时」「下单失败率」）**是怎么来的、口径是什么、自己怎么查到**。
> 指标"数值为什么对不上"的排查见本目录其它 runbook。

## 大盘入口

| 大盘 | 入口 |
|---|---|
| 预报名监控大盘 | https://belong.baijia.com/pre-signup |
| 续班实时 SLA（压测/大促时看） | https://belong.baijia.com/sla?tab=0（见 [续班保障/排查/续班大促压测保障流程.md](../../续班保障/排查/续班大促压测保障流程.md)） |

> belong（碧海神龙）页面是**前端壳**，指标面板实际是内嵌的 **Grafana 面板**（belong 只做登录/壳，数据走 `sre-grafana.baijia.com`）。

## 怎么拿到某个指标的"口径"（关键步骤）

1. 用带登录态的浏览器打开大盘（本机可走 8888 Cookie 代理，或用已登录的 Chrome）。
2. DevTools → **Network**，过滤 `sre-grafana`，两类请求：
   - `GET /api/dashboards/uid/<uid>` = **面板定义**：每个 panel 的 `title` + `targets[].expr` + `datasource` → **这就是口径**；
   - `POST /api/ds/query`、`POST /api/datasources/proxy/<id>/query/gapm` = 取数接口。
3. 不想开 DevTools，本机可用命令行 `chrome-devtools`：
   ```bash
   chrome-devtools list_network_requests <pageId> --resourceTypes fetch --resourceTypes xhr
   chrome-devtools get_network_request <pageId> --reqid <n>     # 看响应体（面板定义/取数结果）
   ```
4. 也可直接开 Grafana 原生页：`https://sre-grafana.baijia.com/d/<uid>/...`，看该 panel 的 **Query / 图例**。

> 记法：**面板 title 在 Grafana 面板定义里；`targets[].expr` 就是指标口径**（多为 promql，也可能是 SQL/gapm）。

## 例子：「预报名状态延时」口径

来自面板 uid `wXhDkxZDk` 的 `targets[].expr`：

```promql
1000 * histogram_quantile(0.8, sum(rate(
  student_data_es_upsert_time_seconds_bucket{
     index=~'ads_large_subclazz_user_index',
     monitorKey=~'presaleStatus',
     environment="prod", result='true'}[1m]
)) by (le,index,monitorKey))
```

= **端到端延时**（不是"ES 调用耗时"）：从**上游 ODS 消息 bornTime**（`PresaleSubjectServiceImpl.sendSubclazzStatusUpdate` 打入 `CURRENT_TIME_MILLIS=messageBornTime`）到 **ES `update()` 完成**（`AdsSubclazzUserSyncService`）。
→ 量的是跨 `ODS源消息 → PresaleSubjectServiceImpl → ADS topic student_data_ads_large_subclazz_user_ordered → AdsSubclazzUserSyncConsumer → ES` 的整条管线延时；**定位要在整条管线拆，不能只看 ES**。详见 [`../看板与指标清单.md`](../看板与指标清单.md) 的「延时口径更正」。
