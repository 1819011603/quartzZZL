# 续班看板指标

续班看板/过程数据排名上的可续学员量、意向类指标（考虑意向率、预报名意向率、不报名意向率等）是怎么算出来的，以及排名维度（小组长、小组长+1）怎么归属，异常口径怎么排查。

## 症状路由

| 症状（用户会怎么说） | 去哪 |
|---|---|
| 看板"可续学员量"和数分（大航海）出的数对不上 | [`可续学员量与数分报表对不上.md`](排查/可续学员量与数分报表对不上.md) |
| 某些小组长/班级名下"不报名意向率"异常偏高（甚至 100%） | [`不报名意向率异常虚高.md`](排查/不报名意向率异常虚高.md) |
| "小组长+1"榜里出现了只是小组长的人 / 某大组长那行是否包含某小组 | [`小组长+1榜里出现小组长.md`](排查/小组长+1榜里出现小组长.md) |
| "小组长"列出现了虚拟架构里没有的组（组内战队长被当成小组长） | [`小组长列出现虚拟架构里没有的组.md`](排查/小组长列出现虚拟架构里没有的组.md) |
