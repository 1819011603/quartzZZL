# 续班推荐加购 · 联报多个年级学科如何展示

> **只解决**：续班推荐链接中，跨年级、多学科联报的分组与展示字段取值。
> 商品缺失走 [续班链接加购商品不展示](续班链接加购商品不展示.md)；纯续推荐缺失走 [在读学员纯续推荐缺失或提示未报名](在读学员纯续推荐缺失或提示未报名.md)。

## 判定入口

先区分纯续、扩科、手动加购及大小班路径。入口为 cart `GET /web/renewal/cart`；以下为本地 cart 分支 `feature-xuban-expand-exclude`、提交 `334fa126` 的代码核验，不代表已核对线上镜像或实际 C 端渲染。

## 排查

1. 返回结构为 `gradeClazzList → clazzDetailDTOList`。联报 `productType=23` 的名称取 `ClazzSetVO.name`，价格取 `totalPrice`，时间取 `timeDesc`，课节数对子班求和；推荐 DTO 不包含逐子班的明细列表。
2. 大班纯续走 `coreHandle → processClazzSet`：同一联报在本次纯续结果中按 `activityNumber` 去重；年级取保留下来的命中后置班课程 `grades[0]`，科目取该课程 `subjects`，不聚合联报全部子班。多个前置课程命中同一联报时，不能据此保证保留最低年级或联报配置顺序第一项。
3. 大班扩科/加购走 `convertClazzSetResultToDTO`：从返回的首个子班加载课程，`resolveGrade` 优先 `configuredGrade`，否则 `course.grades[0]`；`fillSubjectNames` 优先 `configuredSubject`，否则该课程的全部 subjects。扩科结果在 `ExpandSubjectRecommendService` 写入配置年级/学科；加购结果在 `AdditionalPurchaseService` 不设置配置年级/学科，故走首个子班课程回退。
4. 小班路径的扩科/加购由 `enrichRecommendResults` 使用 `ClazzSetVO.clazzes[0]` 构造 `postClassInfo`，再由 `processClazzSetResult` 按配置优先、课程回退的规则生成展示 DTO。不可用组合商品的子班科目并集逻辑代替联报逻辑。
5. 不会因联报包含多个年级/学科就自动在每个年级/学科复制推荐项。扩科配置本身可将同一商品配置到不同年级，当前大小班合并均以 `productId + configuredGrade` 做商品去重，跨配置年级可保留多项；仍受推荐范围、学员后置年级及同年级学科去重等条件影响。

## 验证

针对具体链接，用 baijia-invoke 取得真实响应，逐项核对 `grade`、`subjectNames`、`activityNumber`、`productSkuName`、`price` 和 `recommendType`；同时对照配置年级/学科、命中的后置课程及联报子班顺序。再看推荐页真实渲染，不能把 B 端下单页的「查看班级明细」组件当成 C 端推荐页证据。仅凭本地代码可确认接口取值规则，不能确认生产版本、页面布局或购买后的完整授课内容。
