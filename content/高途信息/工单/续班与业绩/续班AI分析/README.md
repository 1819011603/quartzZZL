# 续班AI分析

学员详情页 AI分析 tab（GAIA 微组件 `aianalysisinformations`）里「续班用户画像 / 沟通概况·沟通总结」等模块的数据来源、过滤条件，以及"某学员为空"的排查方法。

> 该 tab 的画像/摘要由 AI 沟通分析平台分析学员沟通后回传，**不是**直接读页面上看到的通话记录。
