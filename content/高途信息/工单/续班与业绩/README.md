# 续班与业绩

续班关系、可续判定、业绩归属与排行榜相关的线上问题。

## 模块

- [业绩归因](业绩归因/README.md) - 1 条，已解决，含排查方法：覆盖判不出归属人、排行榜显示 0、可续分母、判单开关与回溯四类症状；案例结论是判可续只要课程维度有续班关系配置即可，不要求后置课程已建班。
- [续班关系配置](续班关系配置/README.md) - 1 条，已解决：怎么用 course-center 接口/表独立核验两门课之间是否有续班关系；`course_relation_map` 查不到不代表未命中，判单服务"前置续班课程"策略在当前订单是系列课时还有一条不依赖该表、也不看主讲的"同学部+同科目"兜底分支。
