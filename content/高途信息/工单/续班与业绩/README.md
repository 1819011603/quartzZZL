# 续班与业绩

续班关系、可续判定、业绩归属与排行榜、续班大促保障相关的线上问题与配置。

## 模块

- [业绩归因](业绩归因/README.md) - 1 条，已解决，含排查方法：覆盖判不出归属人、排行榜显示 0、可续分母、判单开关与回溯四类症状；案例结论是判可续只要课程维度有续班关系配置即可，不要求后置课程已建班。
- [续班关系配置](续班关系配置/README.md) - 3 条，已解决/非缺陷：怎么用 course-center 接口/表独立核验两门课之间是否有续班关系；`course_relation_map` 查不到不代表未命中，判单服务"前置续班课程"策略在当前订单是系列课时还有一条不依赖该表、也不看主讲也不校验年级的"同学部+同科目"兜底分支（会导致跨年级续班归属）；另有一条是 OES 续班计划详情页前置/后置产品树不显示课程ID时，直接调 `productRelationList` 接口取 `number`/`bizNumber` 即可，非权限问题。
- [续班保障](续班保障/README.md) - 续班大促（>3W 人次）压测与现场保障：续班学科链路 + 压测前/中/后 checklist + student-data/EES 相关 Apollo key；含 2026-09-22 秋季续班压测的核对/配置记录（`dws.renewal.subject.check.clazz` 等）。
