# 续班服务可见性

EES 班级花名册里「续班服务」/「退费管控」tab 对某些老师**不显示**（灰度未命中）的判定与开通方法。

> 与 `续班服务窗口期` 不是一回事：那边是 tab 能打开、只是显示「非续班期」；这里解决 **tab 根本不出现**。

## 症状路由

| 症状（用户会怎么说） | 去哪 |
|---|---|
| 某（二讲）老师 EES 花名册里没有「续班服务」tab（代课/别人能看到） | [`二讲看不到续班服务tab.md`](排查/二讲看不到续班服务tab.md) |
