# 续班问卷状态

学员在花名册/EES 课后督学页面看到的"续班问卷"发送/提交状态（`renewalQuestionnaireStatus`）怎么算出来、存在哪、谁会写它。

## 症状路由

| 症状（用户会怎么说） | 去哪 |
|---|---|
| 家长已经填了续班问卷，但花名册/EES 显示未发送；或"预报名意向"显示未填写/跟实际不符 | [`问卷已提交但花名册显示未发送.md`](排查/问卷已提交但花名册显示未发送.md) |
| 花名册/EES 显示已提交，但按学员查明细/学员档案-问卷里没有这条问卷 | [`花名册已提交但明细查不到.md`](排查/花名册已提交但明细查不到.md) |
