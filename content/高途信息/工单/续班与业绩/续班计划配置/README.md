# 续班计划配置

OES「续班计划管理」里计划**基础信息**本身的核验与修复：目标学年/学期（页面上的「续班学年」/「续班学期」，即 `renew_master_ext` 的 `TARGET_SCHOOL_YEAR`/`TARGET_SCHOOL_TERM`）以及年级/科目/部门等属性。计划一旦发布，页面基础信息不可编辑，只能改库。

## 症状路由

| 症状（用户会怎么说） | 去哪 |
|---|---|
| 续班计划「续班学年」配错（如 26秋计划配成 2026-2027、应 2027-2028）；计划里按 联报ID/班号 搜不到商品；创建后页面改不了 | [`续班学年目标学年配错.md`](排查/续班学年目标学年配错.md) |
