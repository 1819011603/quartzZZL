# 小班课花名册 ES · 续班服务里搜不到某个学员（花名册有）

> **只解决**：小班「班级花名册」的**续班服务** tab 里按 姓名/手机/userId 搜不到某个学员，而**花名册** tab（或源数据）里明明有他；含「家长预留了英语却找不到人」「花名册在读、续班服务没人」。
> 同班主讲与班主任看到的学员集合不一致走 [`主讲与班主任可见学员不一致.md`](主讲与班主任可见学员不一致.md)；班级完全搜不到/字段缺失走 [`班级搜不到或花名册字段缺失.md`](班级搜不到或花名册字段缺失.md)。

## 判定入口

先固定：学员 `userId`（手机号→userId）、他的 `clazzNumber`、`subclazzNumber`、`smallRenewalNumber`。「花名册有、续班服务没有」先分流成三类，别当数据丢失：

1. **班级范围没圈到他（最常见，非缺陷）**：学员**调班/转班**后，原班已不是他在读的班（原班 `clazzStudentStatus=2 退班(调班)`、`smallCanRenewal=0`、`smallRoundIdx=0`）；他在**另一个班**在读（`clazzStudentStatus=1/3`、`smallCanRenewal=1/2/8`）。续班服务按所选班级过滤，若只圈了原班（或没圈班），他在**一轮**视图里就不出现 → 搜不到。
2. **空班级查询**：小班续班服务 `filter.clazzNumber` 为空 → 接口直接返回 0 条。
3. **真·不可续**：他在当前班 `smallCanRenewal ∉ {1,2,8}`（如英语正价课不在这个班、判 `不可续-无续班关系`），只会落在「续班轮次=不可续」下 → 走 `续班与业绩/业绩归因`「可续状态判不可续」。

> 学员状态是「班级×学员」文档字段（`clazzStudentStatus`：0退班/1在班/2退班(调班)/3在班(调课)）。同一学员在新旧两个班各有一条文档，旧班=2、新班=3，属正常，不是字段错。
>
> ⚠️ **别把「退款(调课)」当退款**：调课/转班是「退原班/原单 + 进新班/新单」，原班状态=退班(调班)、订单侧按"退款"记（业务口径的「退款(调课)」），**不是真退费**（王永诗式"我看学员退款了"多源于此）。这也暴露 B 端订单/售后对"调课"的展示误导，属业务/订单链路口径问题，不是花名册数据错。

## 排查

1. **按 userId 读小班花名册索引，看这个学员到底在哪些班、什么状态**（ES 走 `es-apply` skill 的 `es_workorder.py search`；`ads_small_clazz_user`，学生集群 `es-cn-4xl3gu6ls0007l185`，bean `studentServeClient`）。term `userId` → 每条取 `clazzNumber` / `subclazzNumber` / `clazzStudentStatus` / `smallCanRenewal` / `smallRoundIdx` / `smallRenewalNumber` / `smallPresaleSubject` / `smallPresaleStatus`。
   - 判据：同一 `userId` 若有一条**在读(1/3)+可续**的班、又有一条**退班调班(2)**的班 → 他调班过去了，续班服务应看**在读那条**。
2. **代课成该班二讲/主讲，直调续班服务复现**（三步见 `知识库/cronus/microClazzRoster/continuationService.md`）：`cosplay_login` → 带 `b_client: EES` 直调 → 用完 `cosplay_logout`。
   - 续班服务：`POST <fuwuBase>/bgwApi/component/student-center/roster/small/renewal/page`（`identification=microContinuationService`；**`filter.smallRenewalRoundFilter[]` 必给**：0不可续/1一轮/…；`fuzzyText` 可填 姓名/手机/userId）
   - 花名册：`POST <fuwuBase>/bgwApi/component/student-center/smallClazz/clazzStudentList`（`identification=smallClazzRoster`）
   - **对比三组 `clazzNumber`**：① 只含**原班** → 一轮 0 条；② 含**在读班** → 有；③ 空 → 0 条。②有①无即"班级范围"结论。
3. 家长「预留了英语」看 ES `smallPresaleSubject`（科目 id）/ `smallPresaleStatus`（1已预报）；它是**按班**存的，退班的旧文档也可能带值，别只看班名。

## 验证

- **属班级范围（非缺陷）**：续班服务把 `clazzNumber` 加上**在读的那个班**（或选整个续班计划）就能搜到该 `userId`，且 `smallCanRenewal ∈ {1,2,8}`、`smallPresaleSubject` 在；只圈原班 / 空选则搜不到。
- **不算生效**：`code=0`、默认页没报错、或"重新搜一次/刷新页面"都不能证明；必须以"带在读班的条件能返回该 userId"为准。
