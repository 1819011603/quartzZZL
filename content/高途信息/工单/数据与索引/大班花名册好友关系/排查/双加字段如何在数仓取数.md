# 大班花名册好友关系 · 双加字段如何在数仓取数

> 只解决：bothFriend 双加口径、大数据取数位置与页面取值的一致性核验。

## 判定入口

双加按 userId + 老师 accountId 判断学员和家长两类好友是否同时存在，不是微信与企微同时添加。0=无好友或角色非学员/家长，1=仅学员，2=仅家长，3=两者都有。有效好友可以来自微信或企微，角色按身份关联与配置判断。

## 排查

1. 按 gaotu-ticket-triage 先查知识库，再核对最新代码。页面数据组装 UserAccountInfoDataQueryServiceImpl 按 userId + assistantAccountId 查询 DwsFuwuUserTeacherRelation，未匹配记录默认 0；不得只按 userId 关联，也不得将辅导老师编号直接替代 accountId。
2. 使用 tiangong-datawork 搜表、读 DDL、预览数据。表登记、DDL 正确、元数据更新时间均不能证明有数据或正在同步；预览为空不能直接证明全表为空。
3. relation 与 info 是不同源表。即使都有 both_friend，也需以同一学员、同一老师、同一时间口径与页面核对，不能直接宣称等价。
4. 天级表确认实际最新分区及行数；预览样本分区不一定最新。databus 增量表须确认变更类型、去重及删除处理，不能直接视作当前全量状态。真实结果获取渠道按 tiangong-datawork，不把异步 SQL jobId 当查询结果。

## 验证

字段结构 + 实际数据 + 最新分区/同步时效 + 同键页面值对照，全部具备才可推荐用于复现页面。只取得样本时明确候选状态。具体候选及本次证据见案例索引。
