## 结论

- **直接原因**：teacher-basic 个人中心 `qiweiOptionList` 会对每个候选主体调瓦力云 `getUserInfo`（走企微官方 API）取成员+二维码；新主体"视微新途"在**企业微信侧未把自建应用（微信助手）加入"客户-可调用接口的应用"、未授权外部联系人权限**（企微管理后台"客户"页），企微返回 `48002 api forbidden`，瓦力云取不到成员 → `relation2Option` 返回 null → 该主体选项被丢弃，列表**不显示**、也**没有 `qiweiQrCode`（弹码）**。（企微侧确认人：李浩东）
- **缺配置（`waliyun.corp.idName.map` 白名单）是必要但不充分的前置**：不配 → 候选连白名单都过不了；配了 → 过了白名单仍会因企微 `48002` 取不到成员而被丢。
- 次要：crmApp `multiInfo`(经 linkup) 的 `corpName` 来自 linkup Apollo `corpNameMap`，缺该 corpId → corpName 回退成裸 id `1970326013016745`。
