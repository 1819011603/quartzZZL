# 个人中心企微 · 接口与链路

个人中心-绑定企微（微信助手客户端"个人中心"）的取数/取码链路、接口清单、配置与关键 ID。
由 [`../个人中心绑定企微不显示某主体.md`](../个人中心绑定企微不显示某主体.md) 引用。

## 一、两个页面入口别混

个人中心相关有两套后端，排查时先分清：

| 入口 | 服务 | 接口 | 作用 |
|---|---|---|---|
| 账号列表 / 号状态（号管理） | crm-app-service（crm-service） | `POST /crmApp/scrm/wechat/account/multiInfo` | 列出该账号**已绑定**的企微/微信（含 corpId/corpName/在线状态） |
| 绑定企微-主体/企微选项（含二维码） | teacher-basic | `POST /personCenter/qiweiOptionList` | "绑定企微"里可选的主体/企微 + 弹码（`qiweiQrCode`） |

> 唐稳给的 trace（`189657dc-...`）是 **crmApp multiInfo**；而"绑定企微不显示主体/没弹码"实际看的是 **teacher-basic `qiweiOptionList`**。两者都要看。

## 二、`qiweiOptionList` 链路（取码主链路）

```
微信助手客户端 个人中心
 └─ POST /teacher-basic/personCenter/qiweiOptionList        (teacher-basic PersonCenterController)
     ├─ getQiweiLoginInfos(accountId)                        (LinkUpQiweiService)
     │   ├─ POST /linkup/wechat/relation/getWechatAccountInfoByAccountIds  {accountIds:[...]}   (linkup，读 gaotu_link.tutor_wechat_info)
     │   └─ POST https://ss-waliyun.umeng100.com/open/api/wk/queryRobotInfo {logicIdList:[...]}  (瓦力云，读 um.storm_sun_device，返回 corpId=企微corpid/acctId)
     ├─ getDefaultQiweiRelation(domain)                      ← Apollo personCenter.qiwei.defaultCorpIds1（默认主体）
     ├─ filter(corpId ∈ waliyunService.getSupportedCorpIds()) ← Apollo waliyun.corp.idName.map 的 keySet（白名单）
     └─ relation2Option()  逐个主体
         └─ POST /open/api/wk/official/getUserInfo {corpId, userIdList:[acctId]}   (瓦力云 → ss-official-wk-agent → 企微官方API)
             └─ 拿到成员信息+qrCode 才出选项；返回 null（如企微 48002）→ 该条**丢弃** → 不显示/无弹码
```

## 三、接口清单

### teacher-basic（`teacher-basic.gaotu100.com`，网关前缀 `/teacher-basic`）
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/personCenter/qiweiOptionList` | 绑定企微-主体/企微选项 + 二维码（**本问题主接口**） |
| POST | `/personCenter/qiweiInfo/checkAndSet` | 企微配置校验保存 |
| POST | `/personCenter/checkDescription` 等 | 个人中心其它项 |

### crm-app-service（`crm-app-service.gaotu100.com`，网关前缀 `/crmApp`）
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/crmApp/scrm/wechat/account/multiInfo` | 已绑定企微/微信列表（crm-service `WechatAccountController#multiInfo` → linkup） |
| POST | `/crmApp/scrm/wechat/account/unbind` | 解绑 |
| GET | `/crmApp/scrm/wechat/account/assistantInfo` | 助手信息（登录态/版本） |
| GET | `/crmApp/scrm/wechat/account/jumpClient` | 跳客户端 |

### linkup（`linkup.gaotu100.com`，前缀 `/linkup`）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/linkup/pc/server/tutor/wechat/multiInfo?accountId=` | 老师已绑定企微列表（`TutorServiceImpl#getTutorMultiInfo`） |
| POST | `/linkup/pc/server/tutor/wechat/unbind` | 解绑 |
| GET | `/linkup/pc/server/tutor/wechat/bind/history?accountId=` | 绑定历史 |
| POST | `/linkup/wechat/relation/getWechatAccountInfoByAccountIds` | 按 accountIds 取企微账号信息（`TeacherWechatQueryProcessorImpl`，corpName 用 `corpNameMap`） |

### 瓦力云 open api（`ss-waliyun-open-api`，host `https://ss-waliyun.umeng100.com`，前缀 `/open/api`）
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/open/api/oauth/token?grant_type=client_credentials&scope=all` | 取 token，头 `Authorization: <clientId>:<clientSecret>`，返回 `data.access_token`/`data.token_type` |
| POST | `/open/api/wk/queryRobotInfo` | 按 logicIdList 查机器人（corpId/corpName/acctId，读 um 表） |
| POST | `/open/api/wk/official/getUserInfo` | 按 corpId+userIdList 查主体成员信息（含 `qrCode`）→ **取码关键**，底层走企微官方 API |
| POST | `/open/api/wk/official/queryUserContactQrcode` | 查"联系我"二维码（活码） |

### ss-robot-facade / ss-official-wk-agent（内部 feign）
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/queryWkContactWay` | 按 logicIdList 查企微活码/二维码（`RobotServiceImpl#queryWkContactWay`） |
| POST | `/robotfacade/robot/queryRobotsByUsernames` / `.../queryRobotsByLogicIds` | 机器人信息（含二维码可选） |
| POST | `/officialApi/externalContact/queryUserQrcodeInfo` → `ss_wk_contact_qrcode` | 企微"联系我"二维码 |
| POST | `/officialApi/address/queryCorpUserInfo` → `ss_wk_corp_user_info` | 主体成员信息 |

## 四、关键代码

- `teacher-basic`：`TeacherServiceImpl#qiweiOptionList`（白名单过滤 + 组装）、`#relation2Option`（取成员+二维码，null 则丢）；`WaliyunService#getSupportedCorpIds`（=`corpIdNameMap.keySet()`）、`#decodeCorpId`、`#getQiweiIdsByLogicIds`、`#getQiweiInfoByCorpAndUser`；`LinkUpQiweiService#getQiweiLoginInfos`/`#getDefaultQiweiRelation`；`PersonCenterController#qiweiOptionList`。
- `crm-service`：`WechatAccountController#multiInfo`（→ linkup `TeacherClient#tutorMultiInfo`）。
- `linkup`：`TutorServiceImpl#getTutorMultiInfo`（corpName 用 `corpNameMap`）、`TeacherWechatQueryProcessorImpl#getAccountWechatInfos`。
- `ss-waliyun-open-api`：`WxRobotService#queryRobotInfoByLogicIdList`（corpId 用 `WkCorpConstant.CORP_ID_ENCRYPT_MAP` 转企微 corpid）；`WkOfficialController#getUserInfo`（`/wk/official/getUserInfo`）。
- `storm-lib`：`com.baijia.storm.lib.constant.WkCorpConstant`（`CORP_ID_ENCRYPT_MAP` ← Apollo `ss.lib.constant.corp.id.hook.official.map`）。

## 五、配置项（Apollo）

| app | key | 作用 |
|---|---|---|
| teacher-basic | `waliyun.corp.idName.map` | **支持的主体白名单**（keySet=支持集合；key 是"最终 corpId 口径"，多数为企微 corpid `ww...`，高途/途途等解码后为逻辑 id `1970...`）；value=主体中文名 |
| teacher-basic | `personCenter.qiwei.defaultCorpIds1` | 个人中心默认展示的主体（逻辑 id，逗号分隔） |
| teacher-basic | `waliyun.corpID.decode.map` | 企微 corpid → 逻辑 id（把少数企微 corpid 解码回逻辑 id） |
| teacher-basic | `waliyun.wechat.clientId` / `clientSecret` | 调瓦力云 open api 的凭据 |
| teacher-basic | `wx.work.api.host` | 瓦力云 host（prod `https://ss-waliyun.umeng100.com`） |
| linkup | `corpNameMap` | linkup 侧 corpId→中文名（`multiInfo` 的 corpName 用；缺则回退裸 id） |
| linkup | `tech-yingxiao.ss-lib-constant` / `ss.lib.constant.corp.id.hook.official.map` | 逻辑 id ↔ 企微 corpid（瓦力云 `CORP_ID_ENCRYPT_MAP` 来源） |
| linkup | `tech-yingxiao.ss-lib-constant` / `ss.lib.constant.corp.id.name.map` | 主体 id → 名称 |

> 加新主体时通常要动：`ss.lib.constant.corp.id.hook.official.map`（逻辑id↔企微corpid）+ teacher-basic `waliyun.corp.idName.map`（白名单）；另按需 `personCenter.qiwei.defaultCorpIds1`、linkup `corpNameMap`。
