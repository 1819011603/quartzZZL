# 续班 / 扩科「科目」字段口径（大班续班 & 小班续班）

> 后端：**student-data**（es/facade/dws）。ES 字段写在各花名册 / 续班服务索引文档上，页面（cronus 花名册各 tab）直接读 ES。
> 本文件只讲**科目类字段**（在读 / 续班 / 扩科 / 系列课 / 专题课 / 预报名 / 预售），不覆盖报名、亲密度、可续状态等其它字段。
> 相关页面：`/crm/cronus/clazzRosterOL`（大班花名册，tab `default`/`stageFeedback`/`refundPrevention`/`continuationService`）、`/crm/cronus/microClazzRoster`（小班课花名册，tab `default`/`continuationService`）。

---

## 一、先分清三份「科目」

| 组 | 谁是「本班」 | 落在哪个 ES 文档 | 谁看 |
|---|---|---|---|
| **A 大班本班科目** | 大班班级 | 大班花名册 `ads_large_clazz_user_<年>` / 大班续班服务 `ads_large_subclazz_user_index` | 大班花名册 default tab、大班续班服务 tab |
| **B 大班页上的「小班关联」科目**（`small*`） | 学员读的**小班** | 大班续班服务 `ads_large_subclazz_user_index`（大班辅导班文档） | 大班续班服务 tab 的「小班在读科目 / 续班小班科目」 |
| **C 小班本班科目** | 小班班级 | 小班课花名册 `ads_small_clazz_user` | 小班课花名册 |

- 大班花名册 default tab（`ads_large_clazz_user_<年>`）**不含** B 组 `small*` 字段；B 组只在大班续班服务索引 `ads_large_subclazz_user_index` 上（已实测）。
- 大班文档 `_id = clazzNumber-userId`；大班续班服务 / 小班课花名册文档 `_id = subclazzNumber-userId`；容器文档另有维度。

## 二、源表（一切科目的唯一底数）

| 表 | 库（test） | 分片 | 含义 | 写入方 |
|---|---|---|---|---|

| `dws_small_clazz_user_subject` | `ees_data` | 无分片 | **小班在读科目表**（实体 `DwsGpsClazzUserSubject`，`@DS(mysqlDruidEesDataSource)`） | `OdsSmallRenewalSubjectSyncService`（小班进 / 退班 MQ）、回溯接口 `POST /gps/manual/back/smallClazzUser/subject` 等 |
| `dws_fuwu_clazz_user_presale_subject` / `_presale_coupon` | `ees_data` 等 | — | 预报名（订金班 + 膨胀券） | `PresaleSubjectServiceImpl` |

> 表字段：`clazz_number, user_id, school_year_id, school_term_id, grades(逗号分隔年级), subject_id(逗号分隔科目), course_types, is_del(0正常/1删), department_id_path`。

## 三、A 组：大班本班科目字段

| ES 字段 | 中文 | 口径（关键） | 计算 / 写入 |
|---|---|---|---|
| `studyingSubject` / `studyingSubjectCnt` | **在读科目** / 个数 | 大班在读表里该学员**与本班课程「同学年+学期」的记录**，科目去重排序；**不卡年级、不限本班**（同一学员同季其它大班班的科目也并进来） | DQ `StudyingSubjectDataQueryServiceV2`（`listSubjectByUsersAndTerm`，字段组含 `studyingSubject`）；MQ `StudentBoughtSubjectConsumer` 直接写大班索引 |
| `studyingSubjectName` | 在读科目名 | 查询时把科目 id 转中文 | student-center 展示层派生（不落 ES） |
| `preRegistrationSubject` | 预报名科目 | 命中学员预报名（`renewal_intent_info`）的在读记录科目 | DQ `StudyingSubjectDataQueryServiceV2`（`RenewalIntentInfoDao`） |
| `gradeSeriesSubject` / `gradeSeriesSubjectCnt` | 系列课在读学科 / 个数 | 大班在读表里 `course_types=系列课` 且**年级与本班课程年级有交集**的记录科目 | DQ `StudyingSubjectDataQueryServiceV2` → `CourseTypeEnum.isSeriesCourse`；`StudentBoughtSubjectConsumer` 也写 |
| `gradeTopicSubject` / `gradeTopicSubjectCnt` | 专题课在读学科 / 个数 | 同上，`course_types=专题课` | 同上 |
| `renewalSubject` | 续班科目 | 学员**报名了「本班课程的后置课程」**的科目（后置课程 = `course-center` 续班关系 `CourseNotNormalAclService.mapPostCourseNumberCache`） | `RenewalInfoServiceImpl#calRenewalInfo`（按学年+学期）→ `DwsRenewalSubjectConsumer#upsertEs` 写大班花名册索引 |
| `renewalExpansionSubject` | 续班扩科科目 | 后置课程**同学年学期**的其它课程里学员已报名的科目 − 续班科目 − 在读科目 | 同上 |
| `gradeRenewalSubject` / `gradeRenewalExpansionSubject` | 分年级续班 / 扩科科目 | 同续班 / 扩科，但按**学年+学期+年级**维度计算（`DwsFuwuClazzUserSubject.grades` 展开） | `RenewalInfoServiceImpl#calGradeRenewalInfo`；写 `ads_large_subclazz_user_index`（MQ `AdsSubclazzClazzBatchRenewalSubjectSyncConsumer`，tag `renewal_clazz_batch_subject_tag`；DQ `RenewalGradeSubjectDataQueryServiceV2`） |
| `renewalShopSubject` / `renewalShopSubjectCnt` | 续班商城科目 | 购物车里该学员的科目（去重） | `RenewalShopSubjectDataQueryServiceV2` → `CartEventService#queryCartSubjects` |
| `presaleSubject` / `gradePresaleSubject` | 预售（预报名 / 订金班）科目 | 订金班 + 膨胀券两表合流命中科目 | `PresaleSubjectServiceImpl` |

**大班在读科目实测（2026-10-22，test，学员 `7658127801`）**：其 2026春(C) 大班在读表有 4 行 —— 前置五年级语文 `585960582537144320`(grade15,学科5) + `586329114366044160`(grade21,语文5) + `586329155111610368`(grade21,数学1) + `586329194676480000`(grade21,英语4)。所以文档 `585960582537144320` 上 `studyingSubject=[1,4,5]` → `studyingSubjectName=[数学,英语,语文]`（**含学员在其它班读的数学/英语**，不是只看本班语文）。

## 四、B 组：大班页上的「小班关联」科目（`ads_large_subclazz_user_index`）

| ES 字段 | 中文 | 口径（关键） | 计算 / 写入 |
|---|---|---|---|
| `smallStudyingSubject` / `smallStudyingSubjectCnt` | **小班在读科目** / 个数 | 小班在读表里、**与本大班班级「同学年+学期+同年级」**的记录科目（年级取本大班记录的 `grades`；学期需 OES→CES 比） | `SmallRenewalSubjectService#calRenewalInfo`（大班分支 `getLargeRenewalSubjectInfo` → `collectSmallStudyingSubjects`）；写方 DQ `LargeRelationSmallRenewalSubjectQueryService`（字段 `largeRelationSmallRenewalSubject`） |
| `smallRenewalSubject` | 续班小班科目 | 上面「同年级小班组」的**后置课程**里学员已报名的科目 | 同上 |
| `smallRenewalExpansionSubject` | 续班扩科小班科目 | 后置课程同学年学期年级的其它课程已报名科目 − 续班 − 在读 | 同上 |

⚠️ **「小班在读科目」卡「同年级」**：大班五年级班上，只有学员**五年级的小班**才会出现；若学员读的是别的年级小班 → 该字段为空（**不是没数据，是年级不匹配被过滤**）。
实测坑（2026-10-22）：学员 `7658127801` 的大班前置班是五年级(grade15)，其小班班级是一年级(grade3/11) → 大班续班页「小班在读科目 / 续班小班科目」为空；而**扩科排除读侧不卡年级**（见第六节），所以数学仍被排除 → 出现「列上不展示、扩科却排了它」的口径不一致。

## 五、C 组：小班本班科目字段（`ads_small_clazz_user`）

| ES 字段 | 中文 | 口径 | 计算 / 写入 |
|---|---|---|---|
| `smallStudyingSubject` / `smallStudyingSubjectCnt` | 小班在读科目 | 小班在读表里**同学年+学期+同年级**的记录科目（`GpsSmallStudyingSubjectModel`：`smallStudyingSubjectId` + `courseDepartmentNumber`） | `SmallRenewalSubjectService#calRenewalInfo`（**小班分支** `getRenewalSubjectInfo`）；DQ `SmallClazzUserRenewalSubjectQueryService`（`needLargeSubject=false`）/ MQ `OdsSmallRenewalSubjectSyncService#upsertSmallEs` |
| `smallRenewalSubject` | 小班续班科目 | 上面小班组的后置课程里已报名科目 | 同上 |
| `smallRenewalExpansionSubject` | 小班续班扩科科目 | 扩科（− 续班 − 在读） | 同上 |
| `largeStudyingSubject` / `largeStudyingSubjectCnt` | （小班页上的）大班在读科目 | 小班表按「同学年学期年级」回看大班在读表 | 同上（`SmallRenewalSubjectWide`） |
| `largeRenewalSubject` | （小班页上的）大班续班科目 | 小班组的后置课程命中大班班的科目 | 同上 |

- **门控开关**：`SmallRenewalSubjectService#calRenewalInfo` 里大班分支（`getLargeRenewalSubjectInfo`，产出 B 组）受 Apollo `SmallRenewalSubjectService.needHandleLarge` 控制；**为 false 时 B 组恒空**（test 现值 true）。
- `SmallRenewalSubjectService` 与 `SmallRenewalSubjectV1Service` 两套实现，V1 为旧版（`OdsSmallRenewalSubjectSyncService` 用 `smallRenewalSubjectService`）。

## 六、扩科排除（C 端）读侧口径 —— 与展示口径不同

- 服务：`RenewalInReadSubjectService#listOtherModeInReadSubjects(userId, currentRoomType, schoolYearId, schoolTermId)`（扩科推荐「推荐排除」数据来源）。
- 大班课程 → 取**小班在读**；小班课程 → 取**大班在读**（`dws_small_clazz_user_subject` / `dws_fuwu_clazz_user_subject`）。
- **只按「同学年 + 同学期」过滤（学期按值相等，大班取小班时把 OES→CES 等价也比）**；额外过滤：成人 / 非正价课 / 赠课标签(`studying.subject.course.tag.exclude.list` 默认 `13,4,26,11,27`) / 纯预售 / 上课形式(`renewal.inread.operation.modes`，空=不过滤)。
- ⚠️ **不卡年级**——与第四节「小班在读科目」展示口径（卡年级）**不一致**，是排查「花名册列为空但扩科排除了该科」的关键。
- 开关：扩科节点 `ext_config.excludeMode`（0 无排除 / 1 排除不同授课模式在读，见 `promotions/continuation-classes/renewalProcess.md`）。

## 九、排查提示

- **「在读科目」比实际多** → 该列是**按学年+学期跨本班/跨年级**合并的（见第三节实测），不是只看本班；对照源表 `dws_fuwu_clazz_user_subject`（`is_del=0`）去重集合。
- **「小班在读科目 / 续班小班科目」为空** → 先看**小班班级年级**是否与大班班级年级一致（第四节坑）；再确认 Apollo `SmallRenewalSubjectService.needHandleLarge=true`；再看小班在读表有没有该学员行。
- **扩科排除了某科但页面小班在读科目没显示** → 读侧（第六节）只按学年+学期不卡年级，展示（第四节）卡年级，属两个口径。
- **大班/小班索引字段对不上** → 大班在读 `ads_large_clazz_user_<年>`（studentServe 集群 `es-cn-4xl3gu6ls0007l185`）；续班服务 `ads_large_subclazz_user_index`（eesServe 集群 `es-cn-smw4b9m200004w3hn`）；小班 `ads_small_clazz_user`（studentServe）。
- 查 ES 用 skill `es-apply`；查这些表用 skill `mysql-query`；复现页面接口用 skill `baijia-invoke`（大班续班 `/roster/renewal/page`、小班续班 `/roster/small/renewal/page`，均带 `b_client: EES`）。
