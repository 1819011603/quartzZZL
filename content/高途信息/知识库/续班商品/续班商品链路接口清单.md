# 续班商品链路：接口清单 & 新增商品类型的改动点

> **非页面条目**。用途：**新增一个「商品类型」时，一份「要动哪些接口」的清单**，快速建立改动面。
> 代码仓库：`/Users/gaotu/IdeaProjects/JavaProject/cart`（C 端 + 加购）、`/Users/gaotu/IdeaProjects/JavaProject/order`（下单/购物车）。
> 券判定：`com.gaotu.renewal.preregistration.PreRegistrationCouponConfig#getCouponProductType`（cart-app，默认 **8014**）。
> 2026-10-23 按「膨胀券 8014 落地」梳理。

## 一、商品类型编码

| 类型 | productType | 枚举/说明 |
|---|---|---|
| 大班课（班级） | `2` | — |
| 一对一 | `6003` | `SMALL_CLAZZ_PRODUCT` |
| 小班课 | `6004` | `NEW_SMALL_CLAZZ_PRODUCT`（cart `ProductType.CLAZZ`=6004） |
| 联报（班级集） | `23` | `CLAZZ_SET`（productId=activityNumber） |
| 组合商品 | `51` | `COMBINE_PRODUCT`（productId=组合 SKU） |
| 膨胀券 | `8014` | 可配（默认 8014） |

> 关键差异：班课/联报/含课程子项的组合**自带「班级→课程」链**可解析年级学科；券、纯权益/实物组合**没有**，需另找年级学科来源。

## 二、C 端接口（网关前缀 `/cart` → 服务 `gaotu_cart`）

| 接口 | 作用 | 商品类型处理点（cart 仓） | 新增类型要改什么 |
|---|---|---|---|
| `GET /cart/web/renewal/cart` | 续班推荐 + 加购展示 | `RenewalService#getRenewalDetail` → 大班 `convertResultToClazzDetailDTO`（:697）/ 小班 `convertToRenewalCartVO`（:3531） | **加类型转换分支**（`convertXxxResultToDTO` / `processXxxResult`） |
| `POST /cart/web/renewal/productList` | 换课后商品列表（按商品号重查） | `RenewalService#productList`（:2299-2346，按 productType 分派 setClazzVO/smallRenewalService/setActivity） | **加类型分支**（`setXxxVO`）；注意入参 `ProductListRequest` 现无 `renewalNumber`，券类取数需补 |
| `POST /cart/web/renewal/productSelectConfirm` | 勾选状态保存 | `RenewalService#productSelectConfirm`（:3220，`beforeCourseNumber==null` 直接 return） + `RenewalDataService#productSelectConfirm` / `UserRenewalClazzRepositoryImpl` | **加类型保存键**（券类无前置课号，需按 user+计划+SKU+类型存/删/读回） |
| `POST /cart/web/renewal/price` | 算价 | `RenewalPriceService`（:71-107 / `setProductList` :315-350，按传参桶查） | **加类型入参桶**（券类建议 `skuNumbers`/`couponNumbers`），老 `clazzNumbers` 保持兼容 |
| `GET /cart/web/renewal/productFilterData` | 更换课程-筛选 | `RenewalService#productFilterData` | 加购商品**不涉及**（无更换课程） |
| `POST /cart/web/renewal/productSelectData` | 更换课程-列表 | `RenewalService#productSelect` | 加购商品**不涉及** |
| `GET /cart/web/renewal/preRegistration` | 预报名落地页 | `RegistrationService` | **另一条链路**（与正式续班不同源） |

> C 端加购展示字段（`ClazzDetailDTO`，cart-app/vo/renewal）：`productSkuNumber/productSkuName/productType/price/select/signUp/canChangeCourse/subjectNames/availableScope/beforeCourseNumber`；加购项 `canChangeCourse=false`。
> 券类年级/学科来源：`ProductFeignServiceAdapter#listDisplayableCoupons(renewalNumber,userId)`（**依赖 renewalNumber、不依赖班级号**）；名称/售价：`RenewalDataService#getSingleProductsByClazzNumbersWithCache([SKU])` 的 `productSkuDto.productSkuName/salePrice`。
> 加购项「已报名」signUp：按**加购 SKU 本身**查有效订单（`OrderInfoAdapterFeignService#listBySkuNumbersAndUserIdNoRefundBatch`），口径同联报（按 activityNumber）。

## 三、B 端接口

| 接口 | 服务 | 作用 | 处理点 |
|---|---|---|---|
| `POST /orderComponent/b/cart/addCart` | order-b | 老师为学员加购 | order `CartService#getProductInfos`（未知 productType 一律放行；组合/券特殊处理） |
| `POST /orderComponent/order/cart/detail` | order-b | 购物车详情 | order `CartService#cartDetail`（按类型 buildXxxProductDetails） |
| `POST /component/student-center/renewal/pre/coupon/list` | student-center | 续班计划下膨胀券选品 | 走 product-server 计划级 `listDisplayableCoupons(plan)` → 电商(coupon-a)按【使用中+开售中】过滤 |

## 四、下单链路（order / promotion）

| 接口 | 服务 | 作用 | 新增类型关注 |
|---|---|---|---|
| `POST /promotion/a/fullGive/validateNew` | promotion | 满赠校验 | 别丢弃/拒绝新类型 |
| `POST /web/order/batch/canCreateOrder/v2` | order | 生单校验 | 支持售卖状态/购买上限/重复购买；跳过课程时间冲突/分层考试 |
| `POST /web/order/batch/prepare` | order | 订单确认 | 能返回新类型名称/售价 |
| `POST /web/order/batch/createOrder` | order | 创建订单 | 能创建新类型订单 |

## 五、新增一个「商品类型」的改动清单（勾对）

- [ ] **cart `/cart`**：加类型转换分支（大班 + 小班两条路径），挂入年级分组；命名/售价/年级学科来源定好。
- [ ] **cart `productList`**：加类型分支（换课后重查）。
- [ ] **cart `productSelectConfirm`**：加勾选保存（无前置课号时另开保存键）。
- [ ] **cart `price`**：算价入参桶 + 混合算价；老桶兼容。
- [ ] **order `addCart` / `cart/detail`**：放行/限购显示/明细。
- [ ] **order 生单链路**（canCreateOrder/prepare/createOrder + 满赠）：支持新类型、跳过课程专属校验。
- [ ] **B 端选品/加购**（如券的 `/renewal/pre/coupon/list`）：能出该类型。
- [ ] **年级/学科来源**：班课/联报自带；**券/纯权益类需外部来源**（如券适用范围）。
- [ ] **组合商品**：子项 = 大班课子班(`combineClazzNumberList`) + 小班课子(`combinedSingleProductDtoList` 中 6003/6004)；纯「其他商品」组合过滤；展示取首个子项。
- [ ] **测试数据**：券需 `gaotu.renewal_pre_order_activity_coupon_scope`(券范围) + 计划绑活动(`process_config` type=3/`node_config` type=4/`renewal_link_activity`) + `gaotu.coupon_expand_config`(券商品 `sale_status`=2 开售)。
