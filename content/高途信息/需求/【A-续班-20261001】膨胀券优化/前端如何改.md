# 前端如何改

> 本需求**后端由我们实现**（6 仓 `feature-xuban-20261001`）；**前端由前端同学实现**。
> 后端只提供字段与开关，前端按本文件改。飞书权威版见子需求①技术方案 §15（docx `TmaqdSPepo9Mv9x4fFCcNUEbnYg`）。

## 模块① 膨胀券预报名优化

### C 端（续班预报名落地页 / 下单页）
- **金额选择由后端完成，前端不分叉**：cart 接口 `POST /web/renewal/preRegistration` 返回每张券的 `discountPrice` 已按续班计划 C 端样式开关选好——**开关开=【C 端外显抵扣金额】，关=【抵扣金额】**。前端直接展示 `discountPrice`。展示位置＝券列表每张券的「抵扣/优惠」金额处；**值为 0 时不展示**。
- 如需显式区分，可读 product-server C 端样式接口返回的 `showExternalDeductAmount`（与 `showDiscountAmount` 互斥）。一般无需。

### B 端 OES（promotion-management 前端）
- **新建/编辑预报名活动页**：选券列表新增列【C 端外显抵扣金额】，位置在「抵扣金额」列之后；数值型、两位小数、仅数字与小数点、默认 0、范围 0–100000；支持「批量修改」全部已选券。随 `POST /promotionManagement/preOrderActivity/edit` 商品项新增字段 `externalDeductibleAmount`（单位分）提交。
- **续班计划-C 端样式配置**：新增开关【C 端外显抵扣金额】（非必选、默认关）；与【抵扣金额】开关**二选一**，同时开启后端返回错误「C端外显抵扣金额和抵扣金额二选一，不能同时开启」；可都关闭；外显金额为 0 时即使开启也不展示。
- **B 端下单弹窗券列表**：`POST /renewal/pre/coupon/list` 返回新增 `externalDeductibleAmount`，列表新增一列展示（位置在抵扣金额后）。

## 模块② 小班课学员人数上限修改

### B 端工具箱（boss-counselor：家长会 / 小班课 / 自习室）
- **选学员搜索**：由现在的「客户端过滤 `AddStudent.tsx handleFilter`」改为**服务端搜索**——输入框支持「姓名/ID/手机号/手机号后 4 位」，其中**学员 ID 走批量精确**。
- **调用契约**：`POST /bgwApi/teacher-tool/manage/subclazz/studentList`，请求体新增 `userIds`（number[]，学员 ID 批量精确；**不传/空则返回全部，行为不变**，向后兼容）。姓名/手机号沿用现有过滤口径。
- **输入框文案**：`请输入姓名/ID/手机号/手机号后4位`。
- 人数上限展示直接取 `getSignCountLimit`（后端已按 Apollo 返回 32），**前端无需改阈值**；超限文案后端已同步为「小班课上限32，自习室上限30」。

## 前端涉及仓库

| 模块 | 仓库/页面 | 改动 |
|---|---|---|
| ①C端 | 续班预报名落地页（mweb） | 沿用 `discountPrice` 展示；如需区分可读 `showExternalDeductAmount` |
| ①B端 | OES 预报名活动配置页 + C 端样式配置（promotion-management 前端） | 新增【C端外显抵扣金额】列 + 开关（二选一） |
| ②B端 | boss-counselor 工具箱选学员（家长会/小班课/自习室） | 搜索传 `userIds`；文案更新 |
