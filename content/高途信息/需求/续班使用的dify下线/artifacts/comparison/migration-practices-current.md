# 本次Dify迁移注意事项

|审查点|本次证据与做法|验收边界|
|---|---|---|
|基准配置|复制当前生产完整model_config到TEST，保留prompt、tools和参数；画像替代别名曾额外注入disabled|目标模型名相同不证明有效参数一致；旧别名实验不替代生产配置基准|
|消息渲染|比较下游实收messages的角色、顺序和完整内容；画像实际单user内嵌角色文本|不能仅按提示词编辑器视图把内嵌system改成API角色|
|参数与默认值|沿Dify插件、网关重定向、目标模型到响应usage核实thinking|省略字段不等于关闭；缺失usage不等于0；推理token数量不要求相等|
|输出契约|保存HTTP原文、LLM完整响应与业务解析结果，区分各自层级|随机文本差异不是单独的迁移缺陷证据；json_object是额外约束，需明示|
|知识库|同输入同隔离库验证检索、渲染、生成；两降退费模板未注入片段|检索成功不等于知识进入LLM；不外推生产召回效果；两403问题建议排除|
|身份与调用路径|真实退款入口自动老师身份及SOP已补证，费用头不使用操作人兜底|显式runUser工作流验证不能当自动取老师证明|
|配置发布|按agent局部合并当前值，预览差异、发布、回读，再做同入口实收|草稿或HTTP200不等于生效；共享TEST agent不证明多个生产应用相同|
|启用范围|Apollo配置结合真实调用判断，问题建议403不是停用证据|不因缺权限推定功能下线；生产切换仍未执行|

证据入口：[当前验证矩阵](final-15-verification.md)、[完整对照](final-15-comparisons.json)、[画像有效基准](thinking-effective-alignment.md)、[问题建议实际使用](problem-suggestion-usage-current.md)。本文件总结已证经验，不增加生产上线授权或把子集扩大为全量通过。
