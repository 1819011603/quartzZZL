# 造数项目（data-agent）能力与接口总览

> 范围：只收**下单 / 支付 / 订单 / 商品 / 组合 / 续班（计划·前后置·关联·流程·扩科·预报名·问卷·可续）/ 推荐**相关能力。考试、作业、GPS 分组、线索分配等不在本篇。
> 快照：仓库 `qa-data-agent-service` @ `e3693d4`（release，2026-11-25 拉取）；线上服务 `https://sd.baijia.com/api-qa/data-agent` 健康、**21 个 scenario**（2026-11-25 实测 `GET /scenarios`）。
> 本篇是**索引**：参数以契约为准（`GET /scenarios/<name>`、仓库 `skills/data-agent/tools/<name>.yaml`），别照抄本表拼 body。
> 怎么造具体续班样本 → [续班纯续扩科加购组合_造数与验证手册.md](续班纯续扩科加购组合_造数与验证手册.md)。

## 1. 三种调用方式

| 方式 | 何时用 | 命令 |
|---|---|---|
| HTTP scenario（已部署，免安装） | 线上 21 个场景 | `POST https://sd.baijia.com/api-qa/data-agent/scenarios/<name>/run`，body `{"params":{...},"options":{"traffic_env":"test-eco-1","timeout_s":600}}` |
| 本地 workflow | scenario 没暴露的链路（多数续班/组合/下单 workflow） | 在 `skills/data-agent` 下：`../../.venv/bin/python -m core.executor run-workflow <wf> --params '<json>' --confirm-all` |
| 本地单 tool | 单步调接口 | `skills/data-agent/scripts/da_invoke.sh <tool> '<json>'`（cookie 先 `boss_login` 取一次全程复用） |

**铁律**（来自 skill + 仓库，都踩过）：

1. `traffic_env` 不能漏：漏了会 `code=0` 但不落库。
2. body 必须包 `params`；未知字段直接拒（`additionalProperties:false`）。
3. 价格单位是**分**；非默认年级学科要显式给 `categoryIdPaths`。
4. 成功 ≠ `code=0`：要回读 `saleStatus>0`、课节数>0、老师非空、`order/prepare` 可售（实证 `renew_build` 报 ok 但 saleStatus=0 → 下单「无此商品」）。
5. 先复用 fixture（`~/.claude/skills/gaotu-data-seeding/scripts/fixture_registry.py list`），再新造。
6. `boss_login` 的 `sys` 参数取域名去掉 `test-` 前缀：`test-mi.gaotu100.com`→`boss`，`test-fuwu.baijia.com`→`fuwu`，`test-os.baijia.com`→`os`；默认账号 `tangwen01`（account_id 90247）。
