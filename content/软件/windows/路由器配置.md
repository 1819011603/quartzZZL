
# 简易笔记・光猫 + 老路由器 最终能用版

## 一、接线怎么插（死记）

- 光猫 → 路由器：
    
    **光猫 LAN1 口 ←网线→ 路由器 LAN 口**


光猫 192.168.1.1、路由器 192.168.5.1，**网段本来就是分开的，完全能正常转发，这不是问题**。



## 光猫是拨号还是桥接

你已经说了：

**电脑直接插光猫网口，不用点宽带连接，直接就能上网**

→ **光猫 = 拨号模式（路由模式）**

✅ 确定。

所以路由器必须用：

**上网方式：动态 IP / DHCP**



**光猫 LAN1口 有些上不了网还是咋的  我选的是LAN3  

- **绝对不插 WAN 口**
- 光猫的光纤、电源不动，正常通电

## 二、路由器只改了这 2 个地方


**上网方式：动态 IP / DHCP**
1. **DHCP 服务器：关闭**
2. 设置了自己的 WiFi 名称和密码

## 三、关键生效要点

- 改完设置**必须重启路由器**，否则配置不生效；
- 之前一直没网，就是因为没设置 WiFi、也没重启，导致设置没生效。

## 四、上网方式 / WAN 口怎么处理

- 不用管 WAN 状态（显示断开、全是 0 都正常）
- 不用选 PPPoE 拨号
- 不用改动态 IP / 静态 IP
- 不用管自动侦测

## 五、原理一句话

路由器现在**不当路由器用，只当 WiFi 发射器用**

上网、拨号、分配 IP 全交给光猫，所以一定能上网。
