
### 一个方法 放入一个线程池进行异步 方法中的子方法也放到同一个线程池进行异步 有什么缺点

在刚才情况中 出现了子方法处理完了 但有部分请求一直不执行子方法后的代码 这是为什么


1. 线程饥饿：
    
    - 原因：低优先级的任务（如子方法后的代码）可能一直得不到执行机会。
    - 解决：调整任务优先级，或使用公平调度的线程池。

线程饥饿(Thread Starvation)是一种并发编程中的常见问题,它指某些线程长期无法获得所需的资源而无法继续执行的情况。这种情况通常发生在资源分配不公平或调度策略不合理的情况下。



线程池异步加快速度
1. SynchronousQueue
2. CallerRunsPolicy
3. 主线程执行部分任务 ,让主线程不空等

```
taskThreadPoolExecutor =  new ThreadPoolExecutor(10, 50, 1, TimeUnit.MINUTES, new SynchronousQueue<>(), new ThreadFactory() {  
    @Override  
    public Thread newThread(Runnable r) {  
        return new Thread(r, "task_" + atomicLong.getAndIncrement());  
    }  
},new ThreadPoolExecutor.CallerRunsPolicy());
```


```java
/**  
 * 异步转换集合  
 *  
 * @param origin   源集合  
 * @param function 转换函数  
 * @param supplier 结果集合供应器  
 * @return 结果集合  
 */  
private static <T, U, V extends Collection<U>> V transferCollectionAsync(Collection<T> origin, Function<T, U> function, Supplier<V > supplier) {  
    V result = supplier.get();  
    if (CollectionUtils.isEmpty(origin)) {  
        return result;  
    }  
    // 主线程处理第一个元素  
    T first = origin.iterator().next();  
    List<CompletableFuture<U>> futures = Collections.emptyList();  
    if (origin.size() > 1) {  
        // 异步处理剩余元素  
        futures = origin.stream()  
                .skip(1)  
                .map(item -> CompletableFuture.supplyAsync(() -> function.apply(item), taskThreadPoolExecutor))  
                .collect(Collectors.toList());  
    }  
    result.add(function.apply(first));  
    futures.forEach(future -> result.add(future.join()));  
    return result;  
}
```
