# Cursor 同时操作多个项目的方法

## 方法一：打开多个窗口（最常用）

### 快捷键方式
```
Windows/Linux: Ctrl + Shift + N    → 新建窗口
macOS:         Cmd + Shift + N     → 新建窗口
```

### 操作步骤
```
1. 在新窗口中：File → Open Folder → 选择另一个项目
2. 现在你有两个独立窗口，分别操作不同项目
```

---

## 方法二：使用工作区（Workspace）

### 添加多个文件夹到同一窗口
```
File → Add Folder to Workspace → 选择要添加的项目文件夹
```

### 保存工作区配置
```
File → Save Workspace As → 保存为 .code-workspace 文件
```

下次直接打开这个 `.code-workspace` 文件即可恢复多项目视图

---

## 方法三：命令面板操作

按 `Ctrl/Cmd + Shift + P`，输入：
```
> New Window                    # 新建窗口
> Duplicate Workspace in New Window  # 复制当前工作区到新窗口
> Add Folder to Workspace       # 添加文件夹到工作区
```

## 推荐使用场景

| 场景 | 推荐方法 |
|------|----------|
| 前后端分离开发 | 工作区（同一窗口） |
| 完全独立的项目 | 多窗口 |
| 需要对比代码 | 工作区 |
| 微服务多模块 | 工作区 |
| 不同客户的项目 | 多窗口 |

## 小技巧 💡

```bash
# 从终端直接打开多个项目
cursor /path/to/project1
cursor /path/to/project2

# 或者打开工作区文件
cursor my-workspace.code-workspace
```
