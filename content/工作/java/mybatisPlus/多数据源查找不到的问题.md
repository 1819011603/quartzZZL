**正确的分层架构应该是：**

**Controller层 → Service层 → Dao层(Mapper) → 数据库**

**当前代码的问题：**

- Service层直接继承了MyBatis-Plus的ServiceImpl
    
- 绕过了明确的Dao层边界
    
- Service层承担了数据访问的责任
    

根本原因确实是架构设计问题：

1. 违反了分层原则 - Service层不应该直接继承数据访问的实现
    
2. 职责边界不清 - Service层承担了Dao层的职责
    
3. 数据源管理混乱 - 通过继承而不是明确的Bean依赖来管理数据源
