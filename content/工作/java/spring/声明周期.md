

优雅上下线




在 Spring Framework 中，SmartLifecycle 接口定义了一些常量来表示不同的生命周期阶段。其中，PHASE 常量的值如下：

```java
int DEFAULT_PHASE = Integer.MAX_VALUE;
```

这意味着 SmartLifecycle 的默认 PHASE 值是 Integer.MAX_VALUE，即 2147483647。

这个值的含义是：

1. 它代表了生命周期阶段的默认优先级。
    
2. 较低的 PHASE 值表示更高的优先级。换句话说，具有较低 PHASE 值的 SmartLifecycle bean 会在具有较高 PHASE 值的 bean 之前启动，并在它们之后停止。
    
3. 使用 Integer.MAX_VALUE 作为默认值意味着，如果你不指定自定义的 PHASE 值，你的 SmartLifecycle bean 将在最后启动，最先停止。
    
4. 如果你想要你的 SmartLifecycle bean 更早启动或更晚停止，你可以通过重写 getPhase() 方法返回一个小于 Integer.MAX_VALUE 的值。
