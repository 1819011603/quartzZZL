两个注解

```java
@Aspect  
@Component  
@Slf4j  
public class LinkTraceAspect {  
  
    @Pointcut("@annotation(com.gaotu.tongbao.annotation.LinkTraceTryCatchNotThrows)")  
    public void linkTraceTryCatchNotThrows() {  
    }  
    @Around("linkTraceTryCatchNotThrows()")  
    public Object doAround(ProceedingJoinPoint proceedingJoinPoint) throws Throwable {  
        Object result = null;  
        try {  
            result = proceedingJoinPoint.proceed();  
        } catch (Exception e) {  
            log.info("LinkTraceAspect#doAround error", e);  
        }  
        return result;  
    }  
}


```

```java
  
/**  
 * @author: zhangzeling  
 * @date: 2024/9/5  
 * @description: AopCurrentClassProxyManager  
 * 获取T类的代理类 内部调用方法导致切面注解失效  
 * 为了使得切面注解生效 必须暴露代理类进行调用 可以看@LinkTraceTryCatchNotThrows注解  
 */
@Component  
public class AopCurrentClassProxyManager {  
  
    public static <T> T getObject(Class<T> tClass) {  
       return  (T) AopContext.currentProxy();  
    }  
}
```
