>  自定义的事件如何触发呢

要触发自定义事件，你需要做以下几步：

1. **定义自定义事件类：** 创建一个类来表示你的自定义事件，通常这个类应该继承自`ApplicationEvent`或者它的子类。

```java
import org.springframework.context.ApplicationEvent;

public class CustomEvent extends ApplicationEvent {

    public CustomEvent(Object source) {
        super(source);
    }

    // 可以添加自定义的属性和方法
}

```
2. **发布自定义事件：** 在你想要触发事件的地方，创建自定义事件的实例，并使用`ApplicationEventPublisher`来发布它。
```java
import org.springframework.context.ApplicationEventPublisher;
import org.springframework.stereotype.Component;

@Component
public class MyEventPublisher {

    private final ApplicationEventPublisher eventPublisher;

    public MyEventPublisher(ApplicationEventPublisher eventPublisher) {
        this.eventPublisher = eventPublisher;
    }

    public void publishCustomEvent() {
        CustomEvent customEvent = new CustomEvent(this);
        eventPublisher.publishEvent(customEvent);
    }
}

```

3. **监听自定义事件：** 创建一个实现了`ApplicationListener`接口的监听器类来监听自定义事件。

```java
import org.springframework.context.ApplicationListener;
import org.springframework.stereotype.Component;

@Component
public class MyEventListener implements ApplicationListener<CustomEvent> {

    @Override
    public void onApplicationEvent(CustomEvent event) {
        // 处理自定义事件
        System.out.println("Custom event received: " + event);
    }
}

```

4. **触发事件：** 在适当的时候调用发布者的`publishCustomEvent`方法来触发自定义事件。
```java
@Autowired
private MyEventPublisher eventPublisher;

public void someMethod() {
    // 触发自定义事件
    eventPublisher.publishCustomEvent();
}
```
这样，在调用`someMethod`方法时，就会触发自定义事件，然后监听器会接收到事件并执行相应的逻辑。



> spring的自带的事件和自定义事件的区别在哪里


Spring框架提供了两种类型的事件：自带事件和自定义事件，它们之间的主要区别在于用途和触发方式。

1. **Spring自带事件：**
    
    - Spring框架本身提供了一些预定义的事件，例如`ContextRefreshedEvent`、`ContextStartedEvent`、`ContextStoppedEvent`和`ContextClosedEvent`等。
    - 这些事件表示了Spring容器的生命周期中的不同阶段，比如容器刷新、容器启动、容器停止和容器关闭等。
    - 这些事件是在Spring容器内部自动触发的，无需手动发布。
2. **自定义事件：**
    
    - 自定义事件是根据业务需求定义的，通常用于应用程序的业务逻辑，而不是Spring容器的生命周期事件。
    - 开发人员可以根据需要创建自己的事件类，通常继承自`ApplicationEvent`或者其子类。
    - 自定义事件通常由开发人员在应用程序的特定地点手动触发，使用`ApplicationEventPublisher`来发布。

总的来说，Spring自带事件用于监听Spring容器的生命周期事件，而自定义事件用于实现应用程序特定的业务逻辑，并且可以由开发人员手动触发。
