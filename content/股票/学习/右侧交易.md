## 📚 Part 3：左侧如何判断"现在是低点"？

### 方法1：估值锚定法

|指标|计算方式|如何用|
|---|---|---|
|**PE（市盈率）**|股价/每股收益|历史PE分位数<10%可能低估|
|**PB（市净率）**|股价/每股净资产|跌破净资产可能是底部区域|
|**股息率**|分红/股价|股息率>5%往往是低估区域|
|**PE Band**|历史PE区间图|触及历史最低PE附近|

✅ 趋势一旦形成，往往会延续一段时间
✅ 你能识别趋势信号
✅ 你能在趋势结束时离场

# 五、左侧交易的分批建仓法

## 这是左侧交易最核心的技术

text

```
【金字塔买入法】

原则：越跌越买，但仓位逐渐加大

┌─────────────────────────────────────────────────┐
│ 假设你判断阿里在60-100美元区间是"底部区域"        │
│ 你有10万块准备建仓                               │
│                                                 │
│ 第一笔：100美元买入1万（10%仓位）—— 试探         │
│ 第二笔：90美元买入1.5万（15%仓位）—— 确认在跌    │
│ 第三笔：80美元买入2万（20%仓位）—— 继续下跌      │
│ 第四笔：70美元买入2.5万（25%仓位）—— 接近极限    │
│ 第五笔：60美元买入3万（30%仓位）—— 最后子弹      │
│                                                 │
│ 平均成本 = (100×1+90×1.5+80×2+70×2.5+60×3)÷10   │
│         = (100+135+160+175+180)÷10               │
│         = 75美元                                 │
│                                                 │
│ 如果后来涨到100美元：                            │
│ 盈利 = (100-75)×10万÷75 = 33%                   │
└─────────────────────────────────────────────────┘

关键点：
1. 不是一把梭，而是分批
2. 越低买越多（因为安全边际越大）
3. 必须提前规划好每个价位的仓位
4. 必须预留"比你想的更低"的子弹
```


## 侧建仓的止损设置



```
【基本面止损 vs 价格止损】

左侧交易者通常不设固定的价格止损
而是设"基本面止损"

┌─────────────────────────────────────────────────┐
│ 什么情况下止损？                                 │
│                                                 │
│ ❌ 股价又跌了20%                                 │
│    → 不止损，如果基本面没变，反而应该加仓         │
│                                                 │
│ ✅ 基本面出现重大变化                            │
│    → 止损，因为当初买入的逻辑已经不成立           │
│                                                 │
│ 例如：                                           │
│ • 财报显示利润大幅下滑，且不是暂时性的            │
│ • 公司的护城河被证明不存在                        │
│ • 行业遭遇政策毁灭性打击（如教育股）              │
│ • 公司爆出财务造假                               │
└─────────────────────────────────────────────────┘

这就是为什么左侧交易需要极强的基本面分析能力
因为你要判断：跌是因为情绪，还是因为真的变差了
```

## 右侧交易的优势


```
【对新手更友好】

1. 顺势而为，心理压力小
   买入后往往是涨的（因为趋势已经向上）
   不用承受"买了就跌"的煎熬

2. 胜率更高
   虽然每次赚的可能少一点
   但做对的次数更多

3. 止损容易执行
   趋势破坏了就走，逻辑清晰
   不用纠结"是不是再等等"

4. 不需要深度研究
   看图表、看趋势
   比研究财报简单多了

5. 错了也亏不多
   因为止损线明确
   最多亏一个止损的钱
```

# 七、左侧和右侧可以结合吗？

## 可以！这叫"左侧研究，右侧进场"



```
【进阶策略】

┌─────────────────────────────────────────────────┐
│ 第一步：用左侧思维选股                           │
│                                                 │
│ - 这家公司基本面好不好？                          │
│ - 现在估值低不低？                               │
│ - 有没有安全边际？                               │
│                                                 │
│ 如果答案都是YES → 放入"观察池"                   │
├─────────────────────────────────────────────────┤
│ 第二步：用右侧思维择时                           │
│                                                 │
│ - 不急着买入                                     │
│ - 等待趋势反转信号                               │
│ - 出现右侧信号后再进场                           │
│                                                 │
│ 这样既有安全边际，又不用承受下跌的煎熬            │
└─────────────────────────────────────────────────┘

实战案例：

2022年10月：
左侧研究：阿里估值已经很低，基本面还在
右侧观察：还在下跌，先不买

2022年11月：
技术信号：放量反弹，站上20日线
右侧进场：确认趋势反转，买入

结果：
既买在相对低位（左侧研究的功劳）
又避免了"买了继续跌"的痛苦（右侧择时的功劳）
```
