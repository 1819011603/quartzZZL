## 术语1：抄底

text

```
【抄底】

定义：
在股价大幅下跌后，判断已经到达底部，买入等待反弹。

白话：
觉得跌够了，便宜了，抄个底。

心态写照：
"这股票从100跌到50了，肯定到底了，抄！"

中概股案例：
┌─────────────────────────────────────────────────┐
│ 2022年3月，阿里从150跌到73美元                    │
│                                                 │
│ 很多人觉得"这么大公司，73块肯定是底了"            │
│ 抄底买入...                                      │
│                                                 │
│ 结果：确实是底了，但后面一直在70-100区间震荡       │
│ 2年过去了，依然没回到150                         │
│                                                 │
│ 抄对了底，但没等来预期的大涨                      │
└─────────────────────────────────────────────────┘

抄底的真相：
- 底在哪里，没人知道
- 你以为的底，可能只是半山腰
- "底"往往是事后才知道的

韭菜陷阱：
❌ "跌了这么多，肯定是底了" —— 这是猜测，不是分析
❌ "别人恐惧我贪婪" —— 这话对，但你不是巴菲特
❌ 抄底抄在半山腰，越抄越套

老股民怎么说：
"新手死于追高，老手死于抄底"
"左侧交易（抄底）需要极强的心理承受能力"
```

## 术语2：接飞刀

text

```
【接飞刀】

定义：
在股价快速下跌过程中买入，试图抄底。

形象比喻：
一把刀从天上掉下来，你伸手去接
可能接住刀柄（抄到底），也可能接住刀刃（血流不止）

和抄底的区别：
┌─────────────────────────────────────────────────┐
│ 抄底：跌了很久，觉得稳定了，买入                   │
│ 接飞刀：正在暴跌中，刀还没落地，就伸手去接          │
└─────────────────────────────────────────────────┘

中概股案例：
2021年7月，教育股暴跌
新东方3天跌了80%
有人在第一天跌40%时觉得"超跌了"，抄底买入
结果？又跌了60%

这就是典型的"接飞刀"

核心原则：
"不要试图接住正在下落的飞刀"
"等刀落地，插在地上不动了，再去捡"

实战建议：
暴跌不抄底，至少等：
1. 连续2-3天不再创新低
2. 出现放量阳线（有资金进场）
3. 情绪面的利空落地
```


## 术语3：追高 / 追涨

text

```
【追高/追涨】

定义：
股价已经涨了很多，怕错过，追着买入。

心态写照：
"卧槽涨了30%了，再不买就来不及了！"
"这票要起飞，赶紧上车！"

韭菜心理链条：
┌─────────────────────────────────────────────────┐
│ 看到一只股票涨了                                 │
│      ↓                                          │
│ 心痒，后悔没早买                                 │
│      ↓                                          │
│ 继续涨，更后悔，FOMO（错失恐惧）                  │
│      ↓                                          │
│ 忍不住了，冲进去                                 │
│      ↓                                          │
│ 刚买完，开始回调                                 │
│      ↓                                          │
│ "我一买就跌，我是不是被针对了？"                  │
└─────────────────────────────────────────────────┘

为什么追高容易亏？
1. 你看到的"涨"，是别人已经赚到的钱
2. 你进场时，早期买入的人可能正在出货
3. 股价已经透支了利好预期

中概股案例：
2024年9月，中概股突然暴涨
阿里一周涨了40%，很多人追高买入
结果？10月开始回调，追高的人全被套

但是：
追高不是绝对错误，关键看你有没有逻辑
有些游资专门做"追涨停板"的策略（后面会讲）

韭菜 vs 老手的区别：
┌──────────┬─────────────────┬─────────────────┐
│          │ 韭菜             │ 老手             │
├──────────┼─────────────────┼─────────────────┤
│ 追高理由  │ 涨了好多，怕错过 │ 有明确的突破信号 │
│ 仓位     │ 一把梭           │ 小仓位试探       │
│ 止损     │ 没想过           │ 买入前就设好     │
│ 预期     │ 还要涨很多       │ 赚一段就走       │
└──────────┴─────────────────┴─────────────────┘
```

## 术语4：追涨杀跌

text

```
【追涨杀跌】

定义：
涨的时候追着买，跌的时候吓得卖。

这是韭菜最经典的操作模式：

典型剧情：
┌─────────────────────────────────────────────────┐
│ 股价100 → 你观望                                 │
│ 股价120 → 你心动                                 │
│ 股价150 → 你追涨买入                             │
│ 股价140 → 你慌了                                 │
│ 股价120 → 你割肉卖出                             │
│ 股价100 → 你庆幸"还好卖了"                        │
│ 股价130 → 你后悔"不该卖"                          │
│ 股价160 → 你又追涨买入                           │
│ 股价140 → 历史重演...                            │
│                                                 │
│ 结果：每次都是高买低卖，反复亏损                   │
└─────────────────────────────────────────────────┘

为什么会这样？
- 贪婪：涨的时候想赚更多
- 恐惧：跌的时候怕亏更多
- 情绪化操作，没有纪律

老股民智慧：
"追涨杀跌，幻想美好，四处求助，厌恶思考"
—— 这是韭菜的标准画像

正确做法：
有计划地买入（分批、有逻辑）
有纪律地持有（不被短期波动吓到）
有原则地卖出（达到止盈/止损线）
```

## 术语5：左侧交易 / 右侧交易

text

```
【左侧交易】

定义：
在股价下跌过程中买入，或在上涨过程中卖出。
试图买在最低点，卖在最高点。

特点：逆势操作，抄底摸顶

【右侧交易】

定义：
等趋势确认后再行动。
看到上涨趋势确立了再买，看到下跌趋势确立了再卖。

特点：顺势操作，放弃鱼头鱼尾

图示：
                 
          ╱╲ 顶
         ╱  ╲
        ╱    ╲
       ╱      ╲
      ╱   右侧  ╲
     ╱    卖出   ╲
    ╱      ↓     ╲
   ╱              ╲
左侧              右侧
买入              买入
 ↓                 ↓
  ╲              ╱
   ╲            ╱
    ╲          ╱
     ╲        ╱
      ╲      ╱
       ╲    ╱
        ╲  ╱
         ╲╱ 底

对比：
┌──────────┬─────────────────┬─────────────────┐
│          │ 左侧交易         │ 右侧交易         │
├──────────┼─────────────────┼─────────────────┤
│ 买入时机  │ 下跌中买         │ 确认上涨后买     │
│ 优点     │ 成本更低         │ 胜率更高         │
│ 缺点     │ 可能接飞刀       │ 少赚一段         │
│ 适合谁   │ 高手、长线投资者  │ 新手、趋势交易者 │
│ 心理压力  │ 很大（买了就跌）  │ 较小（顺势）     │
└──────────┴─────────────────┴─────────────────┘

给你的建议：
新手强烈建议用右侧交易！

因为：
1. 左侧交易需要极强的心理承受能力
2. 你需要扛住"买入后继续跌"的痛苦
3. 新手容易把"左侧交易"做成"抄底抄在半山腰"

右侧交易的信号（后面技术课详细讲）：
- 股价突破关键均线（如20日均线）
- 出现放量阳线
- 趋势指标（如MACD）金叉
```

## 术语6：做T / 高抛低吸

text

```
【做T（T+0操作）】

定义：
利用日内波动，先卖后买或先买后卖，降低持仓成本。

背景知识：
A股是T+1（今天买，明天才能卖）
港美股是T+0（今天买，今天就能卖）

但A股也能"变相"做T：
┌─────────────────────────────────────────────────┐
│ 假设你持有1000股阿里（港股）                       │
│                                                 │
│ 早盘：股价涨到105，你卖掉500股                    │
│ 午盘：股价跌到100，你买回500股                    │
│                                                 │
│ 结果：还是1000股，但你赚了500×5=2500块            │
│ 这就叫"做T"                                      │
└─────────────────────────────────────────────────┘

【高抛低吸】

定义：
高位卖出，低位买回，赚取波段差价。

和做T类似，但时间跨度更长：
- 做T：日内完成
- 高抛低吸：可能几天或几周

韭菜陷阱：
❌ 以为自己能做T，结果"高抛"后股价继续涨，踏空了
❌ "低吸"后股价继续跌，套住了
❌ 做T做成了"低抛高吸"，越做成本越高

老股民怎么说：
"做T是高手的游戏"
"新手做T = 交易越多，亏得越多"

给你的建议：
新手不建议做T！

原因：
1. 你判断不了日内高低点
2. 频繁交易增加手续费
3. 容易做反，得不偿失
4. 分散精力，影响主业
```

## 术语7：补仓 / 摊薄成本

text

```
【补仓】

定义：
股价下跌后，再买入更多，降低平均成本。

【摊薄成本】

定义：
通过补仓，让你的平均买入价下降。

数学示例：
┌─────────────────────────────────────────────────┐
│ 第一次：100元买入100股，成本100元                 │
│ 股价跌到80元                                     │
│ 第二次：80元买入100股                            │
│                                                 │
│ 平均成本 = (100×100 + 80×100) ÷ 200 = 90元      │
│                                                 │
│ 看起来不错？只要涨回90就解套了！                   │
└─────────────────────────────────────────────────┘

但这是韭菜思维！

补仓的陷阱：
┌─────────────────────────────────────────────────┐
│ 如果继续跌呢？                                   │
│                                                 │
│ 跌到60 → 再补仓 → 成本摊到75                     │
│ 跌到40 → 再补仓 → 成本摊到55                     │
│ 跌到20 → 没钱补了 → 深套80%                      │
│                                                 │
│ 结果：越补越多，仓位越来越重，套得越来越深         │
│ 本来只亏1万，最后亏了10万                        │
└─────────────────────────────────────────────────┘

什么时候可以补仓？
✅ 基本面没变，只是市场情绪导致下跌
✅ 你有足够的资金和时间
✅ 你对这只股票有深入研究和信心
✅ 你设好了总仓位上限和最终止损线

什么时候不该补仓？
❌ 仅仅因为"便宜了"
❌ 不懂为什么跌
❌ 已经重仓了
❌ 只是为了"摊低成本"的心理安慰

老股民智慧：
"补仓是为了加仓好公司，不是为了安慰自己"
"如果你空仓，你还会买这只股票吗？"
"不会？那为什么要补仓？"
```
