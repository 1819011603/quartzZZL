###  各路资金特征一览

| 资金类型     | 你能看到的数据       | 他们的特点           | 你的对策                  |
| -------- | ------------- | --------------- | --------------------- |
| **北向资金** | 实时披露，东财/同花顺都有 | 聪明钱，提前布局，跑得比谁都快 | 顺势而为，连续3天净流入可跟，连续流出必跑 |
| **公募基金** | 季报披露持仓（延迟）    | 规模大调仓慢，抱团取暖     | 看重仓股方向，但别追高接盘         |
| **游资**   | 龙虎榜，次日公布      | 打板快进快出，做情绪做龙头   | 看席位风格，有些是接力，有些是割韭菜    |
| **量化**   | 很难直接观测        | 高频交易，专吃散户止损单    | 别挂整数价止损（如10.00），挂9.95 |
| **国家队**  | 汇金/社保增持公告     | 只在极端底部出手护盘      | 他们买了不代表马上涨，但代表底部区域    |
| **散户**   | 两融数据、开户数      | 追涨杀跌，高点入场，恐慌出逃  | 反向指标，散户疯狂时谨慎，散户绝望时贪婪  |




## 🌡️ A股情绪周期四阶段模型

这是你每天必须判断的事情：**现在处于情绪周期的哪个阶段？**

text

```
         高潮期 ← 最危险！
          /\
         /  \
        /    \
   升温期     退潮期
      /        \
     /          \
    /            \
 冰点期 ────────→ 冰点期（循环）
     ↑
   最佳买点
```




### 📍 四阶段特征与操作

| 阶段      | 核心特征                      | 情绪指标                     | 你该怎么做          |
| ------- | ------------------------- | ------------------------ | -------------- |
| **冰点期** | 市场极度绝望，没人讨论股票，跌停比涨停多      | 成交额萎缩至地量，连板高度2板就挂，北向连续流出 | ✅ 分批建仓，买跌不追涨   |
| **升温期** | 开始出现赚钱效应，龙头股走出来，人气恢复      | 成交额放大，涨停家数增加，连板高度4-5板    | ✅ 跟随龙头，仓位加到7成  |
| **高潮期** | 满屏涨停，人人都是股神，券商APP挤爆，妖股满天飞 | 成交额天量，连板高度7板+，涨停100+家    | ⚠️ 开始分批止盈，绝不追高 |
| **退潮期** | 龙头开始补跌，赚钱效应消失，情绪急转直下      | 连板股集体炸板，跌停潮，量能萎缩         | 🚫 清仓观望，不抄底不接刀 |


## 📈 核心情绪指标（每天必看）

### 1. 两市成交额

|成交额区间|意味着什么|操作建议|
|---|---|---|
|<7000亿|地量，市场极度冷清|冰点期特征，可以左侧埋伏|
|7000-10000亿|正常水平|观察方向|
|10000-15000亿|活跃，有行情|顺势做多|
|>15000亿|过热，接近高潮|警惕见顶，分批止盈|
|>20000亿|疯狂（如2024年9月底）|极度危险，做好随时撤退准备|


### 2. 涨跌停家数

| 指标       | 健康市场   | 高潮期   | 冰点期  |
| -------- | ------ | ----- | ---- |
| 涨停家数     | 30-60家 | 100+家 | <15家 |
| 跌停家数     | <10家   | <5家   | 30+家 |
| 涨跌比（涨/跌） | >1.5   | >3    | <0.5 |


### 3. 连板高度

| 高度        | 意味着             |
| --------- | --------------- |
| 市场最高板2-3板 | 情绪冰点，没有赚钱效应     |
| 市场最高板4-5板 | 情绪升温，可以做        |
| 市场最高板6-7板 | 情绪高潮，注意风险       |
| 市场最高板8板+  | 妖股横行，散户入场信号（危险） |


### 4. 北向资金

| 情况         | 参考意义       |
| ---------- | ---------- |
| 单日净流入>100亿 | 强烈看多信号     |
| 连续5天净流入    | 外资在建仓，可跟随  |
| 单日净流出>100亿 | 强烈看空信号     |
| 连续5天净流出    | 外资在跑路，必须警惕 |


## 🧠 情绪与预期的核心公式

text

```
股价短期涨跌 = 情绪 × 资金 × 预期差

情绪好 + 资金入场 + 超预期 = 暴涨
情绪差 + 资金出逃 + 低于预期 = 暴跌
情绪中性 + 资金平衡 + 符合预期 = 横盘
```

### 预期差案例（A股版）

|案例|预期|实际|结果|
|---|---|---|---|
|某公司业绩预告+50%|市场预期+80%|低于预期|暴跌10%|
|某公司业绩预告-20%|市场预期-50%|超预期|反而涨5%|
|政策利好落地|市场已经涨了一波在等消息|利好出尽|当天冲高回落|

**记住**：

- **买预期，卖事实**
- 消息出来之前涨的，消息出来那天往往就是卖点
- 消息出来之前跌的，消息出来那天往往就是买点
