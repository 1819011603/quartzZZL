这是最重要的一课，因为**不懂仓位管理的人，赚再多最后都会亏回去**


## 术语1：仓位

```
【仓位】

定义：
你投入股市的资金占你总可用资金的比例。

白话解释：
假设你有10万块准备炒股，你买了5万的股票，那你就是"半仓"。

常见说法：
┌─────────┬────────────┬─────────────────────┐
│ 说法    │ 含义        │ 举例（10万本金）     │
├─────────┼────────────┼─────────────────────┤
│ 空仓    │ 0%，全是现金 │ 10万现金，0股票      │
│ 轻仓    │ 10-30%      │ 2万股票，8万现金      │
│ 半仓    │ 50%左右     │ 5万股票，5万现金      │
│ 重仓    │ 70-90%      │ 8万股票，2万现金      │
│ 满仓    │ 100%        │ 10万全买了股票       │
└─────────┴────────────┴─────────────────────┘

中概股案例：
2022年中概股暴跌时，阿里从300跌到73美元。
满仓的人：亏了75%，10万变2.5万
轻仓的人：只有2万在里面，亏75%是亏1.5万，还有8万现金

韭菜陷阱：
❌ 新手最常犯的错：看好一只股票就满仓杀入
❌ 结果：对了赚很多，错了直接重伤甚至出局

老股民智慧：
"分仓没法暴富，但能苟活"
"满仓单吊"是赌博，不是投资
```



## 术语2：建仓 / 加仓 / 减仓 / 清仓


```
【建仓】

定义：
第一次买入某只股票，建立持仓。

【加仓】

定义：
已经持有某只股票，再买入更多。

白话：股票跌了觉得便宜，或者涨了想追加，都叫加仓。

【减仓】

定义：
卖掉一部分持有的股票，但不全卖。

白话：赚了想落袋为安一部分，或者怕跌先卖一点。

【清仓】

定义：
把某只股票全部卖掉，一股不留。

实战流程示例：
┌─────────────────────────────────────────────────┐
│ 看好拼多多 → 建仓买入100股                        │
│     ↓                                           │
│ 跌了10%，觉得更便宜 → 加仓再买50股                 │
│     ↓                                           │
│ 涨回来了，有点怕 → 减仓卖掉50股                   │
│     ↓                                           │
│ 觉得要跌了 → 清仓，全部卖掉                       │
└─────────────────────────────────────────────────┘

韭菜陷阱：
❌ 下跌时无脑加仓（以为摊薄成本就是对的）
   真相：如果方向错了，加仓只会越亏越多
   
❌ 上涨时舍不得减仓（贪婪）
   真相：不止盈，浮盈永远只是数字，不是你的钱
```


## 术语3：止盈 / 止损

```
【止盈】

定义：
股票涨到你设定的目标价，卖出锁定利润。

白话：赚够了就跑，落袋为安。

【止损】

定义：
股票跌到你设定的亏损底线，卖出认赔离场。

白话：亏到一定程度就认输，不要硬扛。

为什么止损如此重要？（数学课）
┌─────────────┬─────────────────┐
│ 你亏了多少   │ 需要涨多少才回本 │
├─────────────┼─────────────────┤
│ -10%        │ +11%            │
│ -20%        │ +25%            │
│ -30%        │ +43%            │
│ -50%        │ +100%  ← 翻倍！  │
│ -70%        │ +233%           │
│ -90%        │ +900%           │
└─────────────┴─────────────────┘

中概股血泪案例：
2021年买入阿里 @300美元
2022年跌到 @73美元，亏76%
需要涨316%才能回本
到2025年还在100多，依然深套

老股民智慧：
"如果你还没学会止损和离场，你就别谈什么盈利"
"保护你的本金是目前最重要的事情"
"凭运气赚来的钱，终究会凭实力亏回去"

韭菜陷阱：
❌ 不设止损，死扛到底
❌ 心态："只要不卖就不算亏"
❌ 结果：小亏变大亏，大亏变深套，深套三五年
```





## 术语4：浮盈 / 浮亏 / 回撤

```
【浮盈】

定义：
账户上显示的盈利，但你还没卖，还不是真正到手的钱。

白话：纸面富贵，没落袋都不算你的。

【浮亏】

定义：
账户上显示的亏损，但你还没卖。

白话：纸面亏损，但也是真的在亏。

【回撤】

定义：
从最高点跌下来的幅度。

举例：
你10万炒股，最高涨到15万，现在跌到12万
回撤 = (15-12)/15 = 20%

中概股案例：
2021年初买入10万腾讯
2021年2月涨到18万（浮盈80%）
2022年10月跌到7万（浮亏30%，从最高点回撤61%）

如果当时浮盈80%时减仓一半：
- 落袋9万利润
- 剩下的亏了，但总体还是赚的

韭菜陷阱：
❌ 把浮盈当成自己的钱："我已经赚了8万"
❌ 不舍得卖，结果坐过山车，从浮盈变浮亏
❌ "这只股票让我亏了钱" —— 其实是你自己不止盈
```




## 术语5：被套 / 解套 / 割肉

```
【被套】

定义：
买入后股价下跌，账面亏损，不舍得卖，被困住了。

白话：买了就跌，跌了不卖，卡在那里了。

【深套】

定义：
亏损幅度很大，比如亏30%以上。

【解套】

定义：
被套之后，股价涨回来，终于不亏了。

【割肉】

定义：
亏损状态下卖出股票，真正实现了亏损。

白话：认赔离场，壮士断腕。

心理学角度：
为什么割肉这么难？
- 人类天生厌恶确定的损失
- "不卖就还有希望"的幻觉
- 割肉=承认自己错了

老股民智慧：
"当风向不对的时候，认怂不是丢人，那是救命"
"亏损50%需要涨100%才能回本"
"解套可能需要三五年的大好行情，这是最大的时间成本"

正确心态：
割肉不是失败，是止损
把资金从错误的地方解放出来，去对的地方
时间也是成本，深套三年 vs 割肉后抓住新机会
```

### 关于"止损很难"的真相

text

```
你说出了99%股民的真实困境：

道理都懂，但做不到

为什么？
├── 心理层面：人类天生厌恶"确定的损失"
├── 幻想层面：总觉得"再等等就涨回来了"
├── 自尊层面：割肉=承认自己错了
└── 沉没成本：已经亏了这么多，现在卖太亏了

解决方案（后面详细讲）：
1. 买入前就设定止损线（比如-10%），写下来
2. 使用条件单/止损单，让系统自动执行
3. 记住：止损不是失败，是控制损失的手段
4. 问自己：如果现在空仓，你还会买入这只股票吗？
   如果答案是"不会"，那就该卖了
```
