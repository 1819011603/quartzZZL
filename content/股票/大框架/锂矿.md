# 三、“能持续多久”怎么判断？

这才是真正核心。

不是看新闻。

而是看：

# 三个维度

---

# 1）涨价是“情绪”还是“缺货”

这是本质区别。

例如：

|类型|持续性|
|---|---|
|情绪炒作|很短|
|真缺货|很长|

如果：

- 真缺资源
    
- 真库存下降
    
- 真订单增加
    

持续性就会很强。

---

# 2）产业资本开支有没有跟上

周期股核心：

# “供给多久能恢复”

例如锂矿：

如果：

```text
锂价上涨
→ 大家疯狂扩产
→ 1-2年后供给爆炸
→ 周期结束
```

那么：

# 你就知道它不是永恒上涨。

---

# 3）需求是不是结构性长期增长

例如：

|行业|需求性质|
|---|---|
|AI算力|长周期|
|储能|长周期|
|猪周期|短周期|
|面板|中周期|

你必须分清：

# “时代趋势”

还是

# “短期供需”
